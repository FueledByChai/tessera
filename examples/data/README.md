# Bundled example data

Synthetic, randomly generated bars for three fictional symbols (DEMO.US, ACME.US, ZENITH.US): daily bars 2018-2025 and 5-minute bars for DEMO.US in 2024. They exist so a fresh clone can run the example strategies and tests without any market-data subscription. The layout matches the CSV-folders provider format documented in `local.example.toml`.
